# DeepVision

Python 计算机视觉项目。

## 环境要求

- Python 3.10+

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/Zhou-guangxuan/DeepVision.git
cd DeepVision

# 创建并激活虚拟环境
python -m venv .venv
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```
